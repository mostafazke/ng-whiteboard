Examples

Three ways to use ng-whiteboard: the bare canvas, the built-in editor that ships with the component, and your own editor UI on top of the service API.

# Canvas Only

The drawing surface without any editor UI, using [showEditor]="false". Draw with the pen, and use keyboard shortcuts or the service API to change tools.

# Built-in Editor

The default: a plain <ng-whiteboard> comes with the toolbar, properties panel, layers, zoom controls, file menu and export dialog. No extra setup needed.

# Custom Editor

Your own toolbar, layers and properties UI, built with NgWhiteboardService on a canvas with the built-in editor turned off.
