category Custom Shapes

info Shape tool:

The Shape tool (ToolType.Shape, keyboard shortcut S) draws shapes from a list you can extend with any SVG path. Users pick a shape from the ⋯ (More shapes) button at the end of the toolbar. Shapes resize, rotate, fill, snap with Shift, accept arrow bindings and export like any other element.

description 1. Describe the shape

A shape is a ShapeDefinition: an id, a display name and an SVG path d string.

Property Type Description
id string Unique key. Used by shapeId and addShape(), and stored on drawn elements.
name string Label shown as the tooltip and accessible name in the shapes menu.
path string Any SVG path d: absolute or relative commands, curves and arcs, in any coordinate space.

How paths are handled

  • The path is normalized to its own bounding box, so the numbers you use don't matter: a 300 × 300 path and a 1 × 1 path of the same outline give the same shape.
  • The bounding box's proportions are kept for the menu icon and for addShape()'s default height.
  • When the user draws or resizes, the shape stretches to the box. Hold Shift to keep its proportions.
  • Drawn elements store the normalized path, so boards that use the shape still render where it isn't registered.
  • A path that can't be parsed is skipped with a console warning.

add_box 2. Register it

Pass your shapes in the shapes config. They are added to the ⋯ menu after the built-in shapes.

Option Type Default Description
shapes ShapeDefinition[] unset Your shapes. One with a built-in's id replaces that built-in in place.
builtInShapes string[] | boolean true true for all built-ins, false for none, or a list of ids in menu order.
shapeId string first available Shape drawn by the Shape tool until the user picks another.
enableShapes boolean true Turns the whole shapes feature on or off.

code 4. Add shapes from code

addShape(shapeId, props?) places a shape using the board's current drawing style, and props.style overrides it. Width defaults to 100 and height follows the shape's proportions. It returns the new ShapeElement, or null for an unknown id or when shapes are disabled. getAvailableShapes() returns the shapes in menu order.

toggle_on 5. Turn shapes off

With enableShapes: false:

  • the ⋯ button is hidden;
  • the Shape tool and its S shortcut do nothing, and a board on the Shape tool switches to Select;
  • addShape() warns and returns null;
  • shapes already on the board still render.

To hide only the ⋯ button, leave ToolType.Shape out of toolbarTools. That also removes the S shortcut, but addShape() keeps working.
